# brognolibisite

Official website for Brognoli BI and BROGNOLI Studio.

## Stack

- Next.js
- TypeScript
- App Router
- Tailwind CSS

## Local development

```bash
npm run dev
```

Open [http://localhost:3000/pt-br](http://localhost:3000/pt-br).

## Current structure

- `pt-br` and `en` localized routes
- Home
- About
- BROGNOLI Studio
- Pocket Guides
- Videos
- Articles
- Products
- Contact
- Privacy
- Terms
