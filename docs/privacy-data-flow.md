## Remaining account-specific verification

1. Reconfirm that the production Blob store is still `GRU1`; its earlier screenshot showed this value.
2. Check Vercel hosting/request-log location and retention if the account exposes a setting; the Function execution region `iad1` is not evidence for log storage.
3. Review the account's Stripe DPA and Resend signed DPA (Resend dashboard: Settings → Documents). Public provider policies above are the documented baseline, not a substitute for negotiated/account-specific terms.
4. No provider API keys were exposed to the browser or found in the local repository/history scan. The supplied Supabase screenshot confirms only the presence of the three managed AI secret names; their values were not viewed. OpenAI/Anthropic/Gemini project-level data-residency or special-retention controls remain unverified.
5. For Gemini, the owner confirmed the API project is Paid; confirm its billing association remains active because Google distinguishes Paid from Unpaid Services by project billing status.

Do not infer the location of one service from another service's region. The site policy describes the confirmed primary regions and the provider-published processing/retention baselines while noting that international transfers and service-specific exceptions may apply.

The website account area now provides an authenticated JSON export of account-scoped service data and registers account-deletion requests for staff review. Deletion is not automatic; staff must verify the request and review active billing/legal-retention obligations. People who cannot sign in can still contact `support@brognolibi.com` for identity-verified manual handling. Exports do not include API-key values, files/settings stored only on a user's device, or data held directly by third-party providers.
